Grade 5 Mathematics: Equivalent Fractions
Proposed skill link: MAT-FRC

Learning objective

Recognize, create, and explain equivalent fractions using equal parts of the same whole.

Definitions

A fraction represents equal parts of one whole or one group.

The numerator is the number above the fraction bar. It tells how many equal parts are being considered.

The denominator is the number below the fraction bar. It tells how many equal parts make the whole.

Equivalent fractions are different fractions that represent the same amount. Multiplying or dividing both the numerator and denominator by the same non-zero whole number keeps the value unchanged.

Example 1: One half and two quarters

Imagine the same rectangle divided into two equal parts. Shading one part shows 1/2. If each half is divided into two equal pieces, the rectangle now has four equal parts and two are shaded. Therefore, 1/2 = 2/4.

Example 2: Creating an equivalent fraction

Start with 3/5. Multiply both the numerator and denominator by 2:

3 × 2 = 6 and 5 × 2 = 10, so 3/5 = 6/10.

Example 3: Simplifying an equivalent fraction

Start with 8/12. Divide both the numerator and denominator by 4:

8 ÷ 4 = 2 and 12 ÷ 4 = 3, so 8/12 = 2/3.

Common misconception 1: Adding the same number

Adding the same number to the numerator and denominator does not usually preserve the fraction's value. For example, changing 1/2 to 2/3 by adding 1 to both numbers does not make an equivalent fraction.

Common misconception 2: Changing only one part of the fraction

Multiplying only the numerator or only the denominator changes the value. To create an equivalent fraction by scaling, multiply or divide both by the same non-zero number.

Practice question 1

Complete the equivalent fraction and explain your reasoning: 2/3 = __/12.

Practice question 2

Are 4/6 and 6/9 equivalent? Show how you know using multiplication, division, or a visual model.
