# Adaptive gamified learning — coverage inventory

The component is documented in [`docs/adaptive-gamified-learning/`](../../docs/adaptive-gamified-learning/README.md).
This folder keeps the Grade 5 supplied-area inventory the tests lock against.
It is planning evidence, not learner content and not a release decision.

| Path | What it is |
| --- | --- |
| [`coverage/grade5-supplied-area-coverage-v1.jsonl`](coverage/grade5-supplied-area-coverage-v1.jsonl) | One row for each of the 57 supplied areas |
| [`coverage/area-support-types.md`](coverage/area-support-types.md) | Provisional support types per mapped area |
| [`coverage/staged-implementation-batches.md`](coverage/staged-implementation-batches.md) | Finite batches for the mapped areas |
| [`coverage/draft-app-build-plan.md`](coverage/draft-app-build-plan.md) | Development missions; publication stays closed |
| [`coverage/emit_grade5_area_matrix.py`](coverage/emit_grade5_area_matrix.py) | Regenerates the matrix |

The sequential execution plan, specification, prompts, and completion reports are in
`private-notes/adaptive_gamified_learning_plan/` (untracked).
