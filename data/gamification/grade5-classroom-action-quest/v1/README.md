# Grade 5 Classroom Action Quest

Development-only package for `G5-AREA-ENG-01` (`Our Good Behaviour`). The source is one
user-supplied textbook screenshot containing nine written English imperative commands with Sinhala
glosses. It supports written command comprehension only; listening, pronunciation, spontaneous
speaking, grammar production, and free writing are outside the available evidence.

Runtime content and server-only rubrics live in
`backend/app/gamification/content/classroom_action_quest.py`. Public item manifests remove target
poses and target destinations. Unsupported presentations do not expose Sinhala translations.

The three provisional atomic skills remain unreviewed until their exact official curriculum outcome
and source page are confirmed. All human review gates in `manifest.json` remain pending.
