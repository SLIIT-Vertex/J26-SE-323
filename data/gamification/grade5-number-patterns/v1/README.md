# Grade 5 Number Patterns — draft package

This directory records the blocked development package for `G5-AREA-MAT-03`. The six activity
identifiers are provisional internal evidence constructs, not official curriculum codes. Runtime
content is generated and scored by `backend/app/gamification/content/number_patterns.py`.

The package preserves the photographed +2/+4, −2/−4, ×2, ×3, ×4, and ×5 families. It is available
only through the existing development/test `allow_draft=true` gate. No production, research-pilot,
curriculum, Sinhala-language, accessibility, privacy/ethics, or release approval is recorded here.
