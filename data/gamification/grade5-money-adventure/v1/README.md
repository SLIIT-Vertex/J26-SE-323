# Grade 5 Money Adventure draft package

Development-only implementation for `G5-AREA-MAT-10` (`මුදල්`) and universal skill
`MAT-MON`. It contains exactly three games and five atomic activities: denomination
recognition, amount construction, rupee/cent addition, rupee/cent subtraction, and a
practical mini-shop problem.

The supplied textbook photographs are pedagogical references only. No photographed or
AI-reproduced banknote artwork is distributed. Currency is represented with clearly
stylised code-rendered coin and note tokens whose mathematical values and accessible
labels remain live text. Decorative purse, basket, and counter PNGs contain no prices,
denominations, or answers.

All arithmetic is stored in integer cents. Backend scoring checks intermediate working,
carrying, borrowing, price-by-quantity lines, totals, and change. Exact failed-question
worked demonstrations are answer-bearing support only; the shared withdrawal handshake
clears them before a fresh reserved unsupported-after probe. Support history and valid
post-withdrawal independence outcomes reuse the shared durable adaptive episode engine.

The package remains blocked from production delivery until the repository's curriculum,
Sinhala-language, educator, rights, accessibility, answer-leakage, ethics/privacy,
model-safety, and release reviews are complete.
