# Grade 5 Number World draft package

Development-only package for `G5-AREA-MAT-01` (`සංඛ්‍යා`). It is linked to the draft Grade 5
curriculum trace under `G5-MAT-C01` and its two competency levels. Atomic outcomes with medium
trace confidence remain draft; the greatest/smallest and leading-zero activity mappings are
explicitly provisional and require educator/source review.

The runtime definitions live in `backend/app/gamification/content/number_world.py`. The package is
blocked from production and child delivery until curriculum, Sinhala-language, educator, usage
rights, accessibility, answer-leakage, ethics/privacy, model-safety, and release reviews are
recorded. Synthetic tests establish mechanics only.
